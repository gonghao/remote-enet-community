# Wave 13 · 简中、繁中与英文

用户要求为双端应用实现简体中文、繁体中文与英文。语言属于显示偏好；沿用Settings JSON v1、身份/邀请、会话及抓取JSONL格式，不增加第三方依赖。提交和推送按用户明确指令执行。

## 行为与接线

- Settings顶部提供Follow system、简体中文、繁體中文、English；默认按系统首选语言匹配，未知语言回退英文。支持地区/字形匹配，例如zh-CN→zh-Hans、zh-TW/zh-HK→zh-Hant。
- 切换即时更新视图、窗口标题、托盘菜单和提示；不重建Controller、停止会话或清空尚未保存的网络表单、抓取筛选、标记注释及动作完成标记。
- 复用mygo的Locale/SetLocale/OnLocaleChanged和随附简繁中文控件、编辑菜单翻译。程序名、包标识及单实例身份保持固定，窗口显示名称按语言更新。
- 偏好由框架持久化：Windows/Linux使用`<settings-file>.ui/locale`，不同显式配置互相隔离；macOS使用应用自身的语言偏好（AppleLanguages）。支持恢复跟随系统；当前系统语言与显式选择相同，也更新选择状态。
- macOS包声明en、zh-Hans、zh-Hant，并附各语言InfoPlist.strings，覆盖系统显示名称和本地网络用途说明。构建路径、架构和签名边界不变。

## 文案与数据

应用文案集中在`internal/locales/{en,zh-Hans,zh-Hant}.json`，英文源文案作为固定键，格式参数沿用Go fmt语法；`Text`仅用于应用拥有的显示消息。测试检查字典覆盖、格式占位符一致及地区匹配，后续新增界面文字也应入字典。

翻译按钮、无障碍名称、提示、状态、固定产品错误/操作历史、网卡选择说明、连接测试、MGU权限说明、抓取与快捷标记界面。结构化诊断、CLI输出、原始系统/协议错误、地址、指纹、VIN、十六进制和用户标记原文不翻译；数据筛选继续使用原始方向枚举，复制结果保持原字节。
