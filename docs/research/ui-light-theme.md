# Client / Operator 浅色配色研究与替换

日期：2026-11-16。沿用 Wave 6 的紧凑双端布局，采用冷中性浅色主题。

## 选型依据

核对的第一方资料：

- [Microsoft Fluent 2 · Color](https://fluent2.microsoft.design/color)：用中性色建立表面与文字层次，强调色集中于重点和交互；大面积品牌色会削弱层次。
- [Fluent 2 · Color tokens](https://fluent2.microsoft.design/color-tokens)：表面、正文、次级文字、品牌与状态使用不同语义 token，交互状态分别定义。
- [Atlassian · Color](https://atlassian.design/foundations/color/)：neutral、brand、information、success、warning、danger 各有用途，状态不能只当装饰色使用。
- [W3C · Contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [Non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)：以普通文字 4.5:1、关键控件视觉线索 3:1 作为选色检查目标；计算比较使用未四舍五入的值。

比较的候选：

| 方向 | 工作区 / 面板 / 主文字 / 强调色 | 本项目取舍 |
| --- | --- | --- |
| 冷中性浅色 | `#F3F5F8` / `#FFFFFF` / `#1F2937` / `#0F6CBD` | 采用；与主要部署环境 Windows 的工具界面风格协调，浅灰底与白面板保留紧凑分组，蓝色聚焦主操作和实时数值。 |
| 中性灰白 | `#F5F5F5` / `#FFFFFF` / `#242424` / `#1258A8` | 可行，整体更接近黑白灰；本轮选择略带冷色的层次。 |
| 暖白石色 | `#F5F3EF` / `#FFFEFB` / `#303632` / `#28638C` | 可行且偏暖；与本项目当前蓝色工具界面的方向相比，风格变化更明显。 |

这是针对本项目的视觉取舍，不把浅色描述为对所有人更舒适。当前直接使用选定主题，未新增配置字段或主题选择流程。

## 实际 token

配色集中在 `internal/ui/theme.go`，日常界面与启动错误共用同一 Theme，原生窗口首帧背景也引用相同常量。

| 用途 | 颜色 |
| --- | --- |
| 工作区 | `#F3F5F8` |
| 信息面板 | `#FFFFFF` |
| 输入与普通按钮表面 | `#F8FAFC` |
| 主文字 / 次级文字 | `#1F2937` / `#526174` |
| 面板分隔线 / 控件轮廓 | `#D8DFE8` / `#748296` |
| 强调 / 悬停 / 按下 | `#0F6CBD` / `#115EA3` / `#0F548C` |
| 成功 / 等待 / 错误文字 | `#237A4B` / `#8A5700` / `#B42332` |
| 信息 / 等待 / 错误提示背景 | `#EAF3FC` / `#FFF4D6` / `#FDECEF` |

细分隔线仅用于信息分组；输入框与按钮使用较强的控件轮廓。键盘焦点采用不透明蓝色，避免半透明焦点环叠在白底后过淡。选中文本采用低浓度蓝底，选中列表项与主按钮使用白色文字。状态继续保留文字与图标。

## 颜色对检查

通过临时脚本读取实际主题 token 并按 sRGB 相对亮度公式计算。检查 30 组正常启用状态的正文、次级文字、状态、提示及主按钮颜色对，最小值为 `4.801:1`；另检查 8 组控件边界和焦点颜色对，最小值为 `3.163:1`。

| 颜色对 | 对比度 |
| --- | ---: |
| 主文字 / 白面板 | 14.679:1 |
| 次级文字 / 白面板 | 6.324:1 |
| 蓝色数值 / 白面板 | 5.384:1 |
| 白色文字 / 主按钮 | 5.384:1 |
| 成功文字 / 工作区 | 4.859:1 |
| 信息文字 / 信息背景 | 4.801:1 |
| 等待文字 / 等待背景 | 5.564:1 |
| 错误文字 / 错误背景 | 5.708:1 |
| 控件轮廓 / 按下表面 | 3.163:1 |

检查针对所用语义色对；停用控件保留框架的停用视觉状态，不按正常启用文字计算。原有无窗口点击、输入、保存回执、固定角色、日志、缩放与主要控件可见性回归继续运行。
