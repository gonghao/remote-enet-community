# 网络权限助手

macOS 普通权限 GUI 通过系统管理员授权按次启动随包 helper，使用私有 Unix socket 代理单目标设备。设备及路由由 `tunadapter.OpenAuto` 创建和回收，GUI 的身份、密钥和设置不交给 helper。

IPC 帧及设备 MTU 上限为 1500 字节。helper 的入站队列保持 1 包；父端写 worker 必须收到对应 native 写入成功的空 `W` 确认，才处理下一包。调用方取消本次等待后，worker 仍收敛原确认，避免确认串到下一次写入。

父端设备读队列最多保留 16 包，与 `tunadapter` 读取队列一致，包数据预算约 24 KiB。队列满时丢弃新到达的 TCP 包（tail drop），不覆盖已排队包，也不阻塞 IPC 控制帧读取；TCP 通过自身重传恢复丢包。因此应用未及时读取设备包时，`W` 写确认、`C` 清理确认和 EOF 仍可推进。该队列预算不替代写入方向的逐包确认和背压。

测试只使用内存设备与 `net.Pipe`；真实系统授权和原生设备回收需另行验收。
