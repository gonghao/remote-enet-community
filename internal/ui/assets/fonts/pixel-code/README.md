# Pixel Code Bold

顶部四块指标的数值与单位使用此字体。它随应用嵌入并注册，不要求用户安装系统字体；标签与其他正文继续使用原字体和翻译。

- 作者：Qwerasd。
- 上游：[PixelCode](https://github.com/qwerasd205/PixelCode)。
- 固定版本：[v2.2](https://github.com/qwerasd205/PixelCode/releases/tag/v2.2)。
- 来源：[otf.zip](https://github.com/qwerasd205/PixelCode/releases/download/v2.2/otf.zip)内的`otf/PixelCode-Bold.otf`，未修改。
- 字重：700；当前字号24 DIP，关闭`calt`和`liga`以保持测量值的固定字宽。
- 授权：[SIL Open Font License 1.1](OFL.txt)，使用v2.2标签中的原始版权和许可文本；四个平台/角色打包均附带完整许可。
- 发布包SHA256：`528128a720941a84cb006b1c21f7695f7d8035a09e5cb1226c387d4c141c4b32`。
- 字体SHA256：`339f8d920b0c4b4f5053014df85a83b36f48f8c8c6f71757c86f8d3920369c41`。

数字、英文单位与占位符保持机器格式，不经过翻译。引入其他字体或替换版本时，应同步检查数字字宽、英文单位、占位符及字体许可，并检查简中/繁中/英文与100%/150%布局。
